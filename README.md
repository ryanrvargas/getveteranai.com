# Acme

A basic single-page website with a hero, about, features, and contact section.

## Tech stack

- [TanStack Start](https://tanstack.com/start) (React 19 + TanStack Router)
- Vite 7
- Tailwind CSS 4
- TypeScript
- Deployed on Netlify

## Running locally

```bash
npm install
npm run dev
```

The site is served at `http://localhost:3000`.

## Building

```bash
npm run build
```
